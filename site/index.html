Rangefind

A static search engine for large sites: the index is plain files on any static host, and the browser queries it with HTTP Range requests. No server, no search provider.

OSM place search → 175k OpenStreetMap places on a live map: search-as-you-type autocomplete, viewport geo queries, and exact nearest-neighbor — all from static files. Minimal example → The five-document quick-start index: BM25F text search with facets, filters, and typo correction in a single HTML page. Source & docs → Architecture notes, benchmarks, and the full example projects (Wikipedia search with semantic hybrid retrieval, geo, vectors).

What the engine does

  • BM25F text search with typo correction and exact-label rescue
  • Facets with per-query counts, typed filters, and sorted browse
  • Search-as-you-type autocomplete (first keystroke ≈ one small fetch)
  • Lucene-style geo queries: viewport, radius, exact nearest-neighbor
  • Hybrid semantic search from an int8 IVF vector index
  • Snippets and highlight ranges, analyzer-consistent
  • Incremental publishing: deltas as new generations, CDN caches intact

Try it on your site

npm install rangefind, point the builder at newline-delimited JSON, and deploy the output directory to any static host that supports HTTP range requests. The README walks through the config.
